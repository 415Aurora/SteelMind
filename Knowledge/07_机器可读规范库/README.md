# 机器可读规范库

本目录保存供 AI 检索使用的规范文本和结构化参数，不替代原标准文件。

## 文件说明

- `documents.jsonl`：逐页或逐节的规范文本，带标准号、版本、页码、条款号、来源文件和来源链接。
- `chunks.jsonl`：按检索粒度切分的文本块，是向量和全文索引的直接输入。
- `全文文本/`：每个标准一份 Markdown 全文，便于直接打开和人工校对。
- `structured/materials.json`：材料牌号与厚度分组的结构化参数。
- `structured/sections.json`：常用 H 型钢截面结构化参数。
- `standards.db`：SQLite 数据库，包含全文索引、向量和参数查询表。
- `build_state.json`：本次处理的标准数量、页数和文本块数量。

## 文本处理原则

1. 有文字层的 PDF 直接抽取，不使用 OCR，保证字符准确。
2. 无文字层或文字层明显缺失的页面渲染为图片后 OCR。
3. 网页正文直接抽取；网页中的表格和公式图片单独 OCR 并附回原章节。
4. 每条文本块保留标准号、版本、页码或章节号、来源链接和处理方式。
5. OCR 文本只用于检索，工程采用的数值和公式仍需回看原 PDF 对应页。

## 检索原则

- “Q355 板厚 16 mm 的强度”“HN400 截面参数”等精确问题优先调用结构化查询。
- “压弯构件怎么验算”“梁的整体稳定要求”等问题调用混合文本检索。
- 标准号、条款号、荷载值、截面模量、分项系数必须保留原始数值，不交给语言模型自行改写。
