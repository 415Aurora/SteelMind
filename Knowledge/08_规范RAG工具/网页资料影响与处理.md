# 网页资料的影响与处理方案

## 网页资料会有什么影响

1. **表格和公式缺失**：当前公开规范网页大量使用图片承载表格和公式，直接复制文字会漏掉 Q355 厚度分组、活荷载表、抗震表和公式符号。
2. **结构信息丢失**：网页文字没有稳定的 PDF 页码，条款号也可能只存在于标题中。
3. **依赖远程资源**：离线 HTML 中的图片仍可能指向远程地址，断网或网站改版后图片会失效。
4. **版本漂移**：网页可能在原地址更新内容，仅保存 URL 无法证明当时读的是哪一版。
5. **OCR 识别风险**：数字 `0/8`、`1/7`、`m²/m³` 和公式上下标容易出现识别误差。

## 当前处理结果

- GB 50009-2012：已取得完整 PDF，并建立机器可读全文，网页版本作为辅助。
- GB 51249-2017：已取得完整 PDF，并建立机器可读全文，网页版本作为辅助。
- GB/T 50011-2010（2024年版）：保存2016年版完整 PDF、2024年官方局部修订 PDF和网页索引。
- GB 50068-2018：公开网页作为主要全文来源，正文直接抽取，网页内表格和公式图片进行 OCR。
- 所有网页记录保留来源 URL、抓取日期、章节号和原始 HTML 文件。

## 推荐控制措施

- 优先使用正式 PDF；网页只作为补充检索入口。
- 保存网页原始 HTML、下载时间和 SHA-256，不只保存 URL。
- 将正文和图片 OCR 分字段保存，并记录 OCR 置信度。
- 对材料强度、截面尺寸、荷载数值、分项系数等高风险数值，使用结构化参数表而不是 OCR 文本。
- 修订或关键数值进入计算前，回看原 PDF 对应页并由专业人员确认。
