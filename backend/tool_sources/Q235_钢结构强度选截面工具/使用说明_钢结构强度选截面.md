# 钢结构强度验算与离散截面选择

仅需 Python 3.10 或以上，无第三方依赖、不调用 ANSYS 或 OpenSees。把 Python 文件、Q235 截面 CSV 和输入 JSON 放在同一目录即可使用。示例数据是演示数据，不是原工程结果。

```
python steel_section_optimizer.py opensees_forces_example.json --output result.json
```

也可直接调用 `optimize(data)`，返回可序列化的结果字典；`load_library(path)` 可指定截面库。默认使用之前筛选保留的311个Q235截面，重新按几何计算面积和惯性矩，不依赖原CSV的I2/I3轴名。

## OpenSees 数据接口

参照示例 JSON。全局单位必须是 N、mm、N·mm、MPa；例如 kN·m 乘以10^6得到 N·mm。截面局部 x 沿构件，y 沿翼缘宽度，z 沿截面高度。因此 My 为强轴弯矩，对应 Vz；Mz 为弱轴弯矩，对应 Vy。N 正拉负压；本次强度计算取绝对值。

OpenSees接口须先把结果转换到上述局部轴，不能把 element force 向量不经映射直接传入。各单元类型、2D/3D和 localForce/basicForce 的排列不同；节点端力与截面内力的符号也可能不同。

- `members`：物理构件列表，每个id唯一，可使用不连续编号的字符串。
- `length_mm`：物理构件长度，正数；本轮不做长细比验算。
- `current_section`：截面库中的截面名称。
- `design_group`：同组构件共用一个选定截面；可省略，此时每个构件独立选择。一个物理构件若划分多个有限元单元，应汇总各单元内力到该物理构件，或者设置相同分组。
- `forces`：每行包含工况case、位置station，以及同一位置同一工况的N、My、Mz、Vy、Vz、T。必须提供全部字段；已知不存在的分量填0。应覆盖所有设计组合、两端和构件内极值。脚本不自行生成荷载组合，不把不同工况的分量拼接。

## 本轮验算

按GB 50017—2017表4.4.1取Q235设计强度，板厚≤16mm取f=215、fv=125MPa；16<t≤40取205、120；40<t≤100取200、115。全截面统一采用翼缘和腹板较厚者对应的强度，作保守处理。E=206000MPa、泊松比0.3、密度7850kg/m³。

采用弹性截面模量、塑性系数1.0：

σ包络=|N|/A+|My|/Wy+|Mz|/Wz。

强轴剪应力包络=|Vz|Qy/(Iy·tw)，Qy=B·tf·(h-tf)/2+tw·h0²/8。

弱轴剪应力采用保守包络=|Vy|Qz/(Iz·2tf)，Qz=tf·B²/4+h0·tw²/8。此处分母以2tf取值，不计腹板在中线处增大的宽度，形成保守上界。

以两个方向剪应力最大值的和作为剪应力上界τ，检查σ/f、τ/fv及√(σ²+3τ²)/f。正应力和剪应力的最大值未必在同一点，将它们组合是保守筛选；折算应力限值直接取f，不使用可能允许的提高系数。输出的利用率因此可能高于逐点精细验算。

根据本次要求，不验算整体稳定、局部稳定及长细比。输出中的flange_ratio和web_80epsilon_ratio仅为几何参考，非本轮合格判据；截面库本身已经过此前的翼缘筛选。扭矩T非零时，当前强度方法不完整，仅给初选，不给正式截面分配。连接、支承承压、疲劳和变形均不在本轮范围。

## 如何接入外部优化循环

1. OpenSees在当前截面下求解全部工况，形成输入数据。
2. 调用optimize：对每组遍历截面库，按面积从小到大逐个验算，选择满足全部输入内力的最小面积截面。相同钢材下等价于最小单位长度质量。
3. 读取assignments更新各构件截面，重新建模或更新截面并重新求解。截面变化后必须重算自重及相关荷载；不要继续使用旧内力宣称收敛。
4. 外部驱动器检查截面分配是否稳定、重新分析后的强度是否满足；出现往复循环需采用阻尼、保留较大截面或其他策略。此脚本不宣称全局最优，不自带收敛循环。

结果中的current是现截面验算，candidate是建议截面验算，assignments为可回传的截面名称映射；preliminary_proposals包括待补充扭转验算的初选。截面库无可行解时不分配截面，status明确标出，不能忽略。

candidate_sections提供A、Iy、Iz、E、G等。J_approx是薄壁近似，不是精确扭转刚度；没有提供剪切面积和翘曲刚度。实际接入不同OpenSees单元时应由适配层完成相应截面构造和参数转换。单元轴变换、模型约束、分析阶次和荷载组合仍由外部计算程序负责。

依据：GB 50017—2017第4.4节及第6.1节弹性强度计算；原MAPDL中的铝合金稳定公式、长细比修正与局部稳定限值均不移植。
