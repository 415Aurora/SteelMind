# 数据单位与内力正负号

## 固定单位

| 量 | 契约单位 |
|---|---|
| 全局坐标、沿杆位置 | m，字段 `_m` |
| 截面尺寸、位移 | mm，字段 `_mm` |
| 面积、惯性矩、截面模量 | mm²、mm⁴、mm³ |
| 力、弯矩 | kN、kN·m，字段 `_kN` / `_kNm` |
| 均布荷载 | kN/m，沿杆件实际长度 |
| 弹性模量、强度、应力 | MPa = N/mm² |
| 转角 | rad，逆时针为正 |

`units.py` 提供显式转换帮助函数，不会根据数值大小猜测单位。例如 N→kN 除以1000，N·mm→kN·m 除以10⁶。所有报告四舍五入仅用于显示，输入和 JSON/XLSX 数值保持原值。

## 坐标与端部力

全局 X 向右，Y 向上，弯矩绕平面外正 Z 轴逆时针为正。杆件局部 x 从 I 端指向 J 端，局部 y 是其左法向。

```text
       local y (left normal)
       ↑
I ● ───┼──────────── ● J   → local x
```

节点荷载、位移和支反力使用全局坐标；`uniform_member` 荷载与 `member_end_forces` 使用杆件局部坐标。正端弯矩均为逆时针。`Ni/Vi/Mi` 与 `Nj/Vj/Mj` 是**节点作用于杆件**的端部力，不是杆件作用于节点的力。

截面内力在正 x 法向切面上定义：N 沿 +x 为拉力，V 沿 -y 为正，M 逆时针为正，对水平 I→J 梁代表正弯矩下挠。与端部力的转换是：

| 截面 | N | V | M |
|---|---|---|---|
| I端内侧 | `-Ni` | `Vi` | `-Mi` |
| J端内侧 | `Nj` | `-Vj` | `Mj` |

例如 6m 简支梁承受向下10kN/m均布荷载：两端作用于杆件的竖向力均为 +30kN，杆端弯矩为0；截面剪力由 +30 变化至 -30kN，跨中正弯矩45kN·m。

上游若采用其他符号，必须先在适配器转换；不得仅改字段名。跨中位置从 I 端起算。剪力突变时，用相同 `x_m` 的 `side=left/right` 两条记录表示两侧值，不能用同位置的 `single` 记录混淆。

## 释放和支座

`release_i/release_j` 只表示杆端转角释放。支座 `ux/uy/rz=true` 表示对应自由度约束。图上的释放圈和支座符号表达分析边界，不表示已经设计了实体连接或基础。

## 截面及来源

`property_basis=idealized` 表示无圆角的理想 H/I 截面，按输入几何核对 A、Ix、Iy、Wx、Wy，超过1%误差拒绝生成。`catalog` 保留来源可追溯的上游型钢表数值，几何图示不代替型钢表，也不以理想矩形公式覆盖圆角贡献。强轴 x 为水平翼缘的形心轴，弱轴 y 为腹板中心线。

每条追溯记录的 `result_path` 使用 RFC6901 JSON Pointer，定位规范化 `DesignBundle` 内的值，例如 `/analysis/reactions/0/fy_kN`。公式字符串只用于显示，不会被执行。
