# 简支梁解析基准与展示案例

## 解析基准

`examples/analytic.json` 使用水平、等截面、线弹性 Euler–Bernoulli 简支梁。I端铰支、J端竖向约束，梁端转角释放；全跨均布竖向荷载向下。它只用来核对数据映射、单位、端力符号、追溯和文件一致性，不是完整钢框架规范设计案例。

| 输入 | 数值 |
|---|---|
| 跨径 L | 6m = 6000mm |
| 均布荷载 q | 10kN/m = 10N/mm |
| 弹性模量 E | 206000MPa |
| 理想截面 | H300×200×8×12，无轧制圆角 |
| A | 7008mm² |
| Ix | 113606784mm⁴ |
| Wx | 757378.56mm³ |

独立手算关系与预期结果：

- 两端竖向反力：`qL/2 = 30kN`。
- 沿程截面剪力：`V(x) = q(L/2-x)`，I端内侧+30kN，J端内侧-30kN。
- 沿程截面弯矩：`M(x) = qx(L-x)/2`，两端0，跨中+45kN·m。
- 跨中相对挠度绝对值：`5qL⁴/(384EIx) = 7.210614792876748mm`，实际竖向位移为负值。
- 弹性弯曲应力：`45×10⁶/Wx = 59.41546589330439MPa`。
- 支点转角：I端`-0.0038456612228675987rad`，J端相反。

示例中 ULS/SLS 两个组合均取单工况系数1，仅用来验证不同组合字段的传递。235MPa应力比较值及L/300挠度比较值均为演示设置，不能当作任何实际工程的规范设计强度或适用限值。缺少稳定与框架位移等项目，因此总体仍标识为 `INCOMPLETE` 和草稿。

`tests/test_analytic.py` 直接使用独立期望值与手算关系检查生成的数据，不调用通用结构求解器。计算书/XLSX/CAD的测试进一步检查这些值和几何尺寸是否正确传递。

## 三层两跨展示案例

`examples/demo.json` 有12个节点、15根杆件，跨距6m和8m，三层层高均为3.6m。数值来自可重复的展示数据构造，并非结构求解器计算结果。它用于检查多层、多跨、多截面、编号与分页。

该数据刻意保留 B11 强度检查的 FAIL：需求270MPa，比较值235MPa。源记录、报告、结果表、文件清单和API均应保留 FAIL；即使文件全部生成成功，也不得据此显示“结构通过”。

## 小组真实案例替换步骤

1. 由计算负责人提供与实际输入对应的分析和验算结果，并填写工具版本、规范版本和条款来源。
2. 按 `CONVENTIONS.md` 转换单位、局部坐标、杆端力作用方向和释放信息。
3. 补齐验算覆盖清单中的记录，合理不适用项写明依据；缺失项不填造零值。
4. 用独立人工计算或其他程序对照关键结果，将对照证据加入课程案例验证报告。
5. 生成新成果，检查上游验算项汇总、草稿原因、图纸编号和追溯定位。
