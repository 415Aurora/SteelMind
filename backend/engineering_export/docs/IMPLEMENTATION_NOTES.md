# 实现取舍与使用边界

| 决定 | 原因及影响 |
|---|---|
| 独立Python项目，不改动参考资料所在仓库 | 当前交付目录是新的独立目录；小组可整体复制或通过SDK/HTTP接入，不依赖本机原始资料路径 |
| XLSX使用openpyxl | 与已确认计划一致，便于跨平台Python服务部署；机器追溯以JSON快照为准 |
| Python3.11与3.12依赖分支 | 锁文件按Python版本选择NumPy/ContourPy兼容版本；实际测试环境为3.12，3.11仍需目标机验证 |
| 部分导出失败保留已确认文件 | PDF/DWG失败时仍可获取DOCX/XLSX/DXF；失败留下的残缺文件不登记、不打包 |
| Excel超长单元格明确失败 | 超过32767字符时不生成被截断的XLSX；DOCX及完整JSON保留，整体状态partial |
| 同一输入每次生成新目录 | 牺牲去重存储，避免旧文件混入新成果；按normalized_sha256判断是否同一输入快照 |
| 公式仅展示，不解释执行 | 不执行任意表达式；标量比较、引用和追溯一致性可校核，任意公式和规范适用性由上游负责 |
| 教学覆盖清单独立于数据声明 | 阻止仅靠自行缩减required_checks获得完整状态；清单本身仍需计算负责人核对，不宣称规范完备 |
| 方案图不深化连接与三维构造 | 表达分析模型、编号、截面和约束；不能替代施工图、节点设计或工程审查 |

Word/CAD编辑端需具备对应字体。随包提供的Noto字体可按OFL授权安装；Windows的LibreOffice需安装该字体或指定已安装字体。原生绘图文字和尺寸保持可编辑。

输入只支持等截面二维直杆，坐标单位m、图纸模型单位mm。偏心、刚域、端部偏移、变截面和三维模型不能静默简化。复杂密集图形仍应由制图人员检查标签和布局；正常三层两跨样例已经过重叠检查与人工视图检查。

没有接入组员计算引擎，因此示例不会被描述为真实完整钢框架规范验算。三层两跨演示含FAIL，解析基准缺项，二者的标识均保留在成果中。
