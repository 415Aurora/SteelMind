# 自重案例的待补充信息怎么处理

本次已确认只做框架自重范围。可以生成计算书并保留未闭合项，不能把报告INCOMPLETE手改为通过。

| 类别 | 你应做什么 | 当前程序的处理 |
|---|---|---|
| 荷载系数、重要性系数、梁挠度限值 | 由设计/计算负责人确认，按下列现有字段填写，重新上传并运行工作流2 | 已接入参数读取；未填采用报告列明的默认值 |
| 柱计算长度、屈曲曲线、支撑/侧移条件 | 按实际模型和边界由计算组确定，提供双向计算长度及依据 | 压弯稳定完整公式尚未实现，不能只填Excel就消除待办；需继续开发或交接独立验算 |
| 梁侧向支承、无支撑长度、受压翼缘约束 | 查结构图和连接/楼板约束，由计算组确认适用条件 | 稳定适用性及公式尚需实现；几何长度不直接等于计算长度 |
| 板件等级、局部稳定、有效截面 | 根据H/箱形板件尺寸与应力分布由计算组补充计算及依据 | 当前只算给定毛截面强度，未完成有效截面复核 |
| 柱/框架整体变形 | 节点位移已计算；需确认整体变形控制条件、层的对应关系和限值 | 柱不套用梁L/400；待完成体系适用性、二阶效应及整体稳定检查 |
| 抗剪/折算应力保守界超限 | 让计算组精算第一面积矩与实际截面应力，不能直接认定真实应力超限 | 保守界满足可判单项满足；保守界超限标PENDING |
| 风、地震、楼面附加荷载及完整组合 | 本次不扩展，保留范围说明；日后扩展须重新提供作用、质量源和组合 | 不混用历史3D3S参考值 |
| 连接、柱脚、基础 | 由对应设计负责人另行验算，本次保留范围外说明 | 不属于当前杆系成果模块覆盖范围 |

## 现阶段可直接修改的控制字段

在Excel的Design_Controls表按原第4行表头新增或修改记录，用parameter_id列匹配、value列填写：

| parameter_id | value默认值 | 含义 |
|---|---:|---|
| permanent_load_factor | 1.3 | 自重承载力分项系数，本通道不接受低于1.3 |
| importance_factor | 1.0 | 重要性系数，本通道不接受低于1 |
| beam_deflection_denominator | 400 | 梁挠度限值分母；实际用途及取值由设计负责人确认 |

只修改经确认的值，不通过降低要求“消除”未通过记录。填写后重新上传Excel并运行工作流2。未确认时可继续采用明确列出的默认假定，生成草稿并保留缺项。其他上述稳定参数尚未建立可执行字段/公式接口，不要随意添加列后认为已完成验算。

## 变形与三维图的含义

节点总位移是原始XYZ位移向量的长度，梁相对挠度相对于杆端连线或悬臂根部切线计算，二者不是同一个指标。本次案例分别约0.17713mm与6.28679mm。三维变形曲线由均布自重下分段连续位移场取样得到，显示倍数只放大画面，不改变计算数值。色标给出的内力范围为沿杆每根构件的控制值；颜色按绝对值，非沿杆完整内力图。
