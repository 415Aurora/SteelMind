# 龙岩自重案例验算修正版

已按用户确认，将72根BY次梁截面转角90°修正为0°，H梁腹板竖直；未采用组合楼板侧向约束，未新增支撑或荷载。原工作簿和旧案例保持可追溯。

## 本次数值

- 节点120、杆件248；总自重1296.46035159 kN，修改前后一致。
- 最大梁相对挠度由6.28679260 mm降至0.229145948 mm；节点最大总位移约0.177133162 mm，未改变竖向轴向压缩主导的节点位移。
- 新增翼缘宽厚比、腹板保守S4筛查与区格稳定适用性；按本工况连续杆段受压情况判定压弯稳定是否适用。
- 分项统计1472 PASS、0 FAIL、600 PENDING、616 NA。包含板件汇总项与分项，不能用总数量衡量独立验证程度。所有248构件均有已完成项通过，也均仍有稳定或有效截面缺项，整体保持INCOMPLETE。

## 已验与不适用

H梁翼缘采用(b−tw)/(2tf)≤15√(235/fy)，忽略圆角对外伸宽度的有利扣减；主梁约5.559≤12.204，次梁9.7≤12.204。无受压梁仅免受压/压弯稳定，不免侧扭稳定。闭口箱柱不重复套H梁侧扭项目，仍需双轴压弯稳定。柱不套梁挠度，整体层间位移控制列项目缺项。

## 仍需专业闭合

1. 全部152根H梁：不采用楼板约束，仍需实际无支撑长度、受压翼缘支承与端部抗扭条件，完成侧扭稳定。端弯矩释放不能等同抗扭边界明确。
2. 72根次梁：腹板530/6=88.333，高于80√(235/355)=65.089，虽满足纯受弯S4门槛，仍需区格、加劲肋及边界对应的腹板稳定验算。未用假设的端加劲肋或楼板约束获得通过。
3. 96根箱柱：按四壁均匀受压的保守S4筛查，净宽厚比38，高于45√(235/355)=36.613。此为保守充分条件未满足，不表示承载力已失败；应以实际应力梯度分类并精算有效截面，保留毛截面权威属性。不能用仅特定抗震条件适用的应力放宽直接消除提示。
4. 28根带微小受压的主梁：不能按纯弯免压弯稳定；均匀受压腹板45ε筛查偏保守，需要应力分布/有效截面精算。受压幅度与依据在逐杆JSON内保留。
5. 双向计算长度/屈曲曲线、框架二阶与初始缺陷、整体位移控制、完整组合、节点柱脚基础不因本次自重分项通过而自动通过。

这些缺项分为“真实边界尚未定义”和“程序公式尚未实现”。当前版本不会因为仅填写一个长度就自动完成稳定判定。毛截面应力通过也不能替代仍待核的有效截面强度。

## 复现与交接

在源码包项目目录执行`bash scripts/run_longyan_case.sh`。只使用项目虚拟环境，不需要模型API Key；首次依赖准备方法见examples/longyan-selfweight/README.md。计算书PDF需LibreOffice。每次输出独立目录。

默认input.json为已授权的腹板竖直修正版；input-before-orientation.json及expected-before-orientation.json为原90°版。orientation-comparison.json列出全部72项修改及前后数值、输入哈希。使用`--input examples/longyan-selfweight/input-before-orientation.json`可重算修改前输入，绝不需编辑旧基线来“对上结果”。

网页仍缓存旧模型时，需重新导入修正版输入、运行工作流2后再运行工作流3；旧结果不会自动变成新结果。调用方也可直接将修正版JSON表对象送到`POST /workflow/explicit-model/run`，请求体为`{"payload":{"tables":...}}`，再向`POST /workflow/engineering-outputs/run-stream`发送`{"payload":{"explicit_tables":...}}`。
