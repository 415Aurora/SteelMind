# 自重案例验算适用性与次梁朝向修正

## 已确认范围
用户要求依据《案例验证.docx》尽量补全验算。用户已明确不采用组合楼板侧向约束；仅以当前杆系判断。用户授权将72根BY次梁由截面转角90°修正为0°，H梁腹板竖直，并保留前后对照。保持Q355B、支座、释放、截面权威属性和仅框架自重荷载。

## 原因与修改
1. 原程序给所有杆件加入相同待办，造成无受压梁、箱柱梁侧扭以及柱梁挠度重复待办。
2. 按连续杆段轴力极值判断是否存在受压，记录1e-8 kN数值容差；无受压仅免受压稳定，梁侧扭独立判断。
3. 闭口箱柱不重复套H梁侧扭；保留柱双轴压弯稳定。柱不套梁挠度，整体位移限值另列项目缺项。
4. 新增H/I翼缘S4宽厚比、腹板保守S4门槛和腹板区格稳定适用性。H-welded按H几何分类。纯强轴弯曲且无轴压/弱轴弯扭时采用124ε腹板S4门槛；其他受力按均匀受压45ε作保守充分条件。超过保守门槛仅表示需要精算，不判真实承载失败。
5. 腹板S4通过不替代6.3局部稳定。仅无轴压、纯强轴弯曲、均布自重应力场且h0/tw≤80ε时免附加区格验算。超过80ε保留边界、加劲肋及区格验算待办。节点局部承压另在项目连接缺项中保留。
6. 箱柱按45ε，箱梁按42ε作均匀受压S4充分条件。未过门槛保留有效截面/应力分布精算，不调用抗震应力放宽来获得通过。
7. 构件overall status保持FAIL优先、缺项INCOMPLETE；另列completed_check_status与coverage。界面显示已验项通过及缺项数量，不将其画成全部通过。
8. 修正输入另留input-before-orientation.json、原expected及72项修改清单；不修改Downloads原文件。重新生成当前基线、计算书、表格、XYZ DXF和25页图册。

## 依据和差异
《案例验证》正文对次梁免整体稳定的前提是组合楼板有效侧向约束。本次明确拒绝采用该前提。参考图材质Q235B、552构件与当前正文Q355B、248构件不一致；不能直接移植历史内力或通过结论。规范核对采用仓库全文与济南住建部门公开GB50017-2017 PDF的3.5、6.3、8.2、8.4相关条文。

## 验证
新增适用性、真实内力、H-welded别名、箱梁42ε门槛、超保守界不得假通过、90°/0°解析挠度比回归测试，先记录失败再实现。运行已有后端/导出/CAD测试、Node图例检查、8/16段案例复算及文档逐页渲染。交付保留未闭合项、原始输入和复现材料，不提交git。
