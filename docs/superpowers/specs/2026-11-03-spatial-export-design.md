# 三维框架成果链路扩展

用户已授权扩展目前因三维结果被二维契约阻断的成果链路。沿用现有本机隔离环境、网关、生成工具和前端入口，不更改分析或验算算法。

新增 SpatialResultBundle/1.0，直接保留最终分析的 XYZ 节点、六自由度、十二项杆端力、实际逐构件截面和原始验算文字；二维 DesignBundle v1.0 不改变。坐标 m，位移 mm，转角 rad，力 kN，力矩 kN·m；绘图坐标按 mm 1:1。Y 为竖向；局部轴及作用力保持 OpenSees 上游约定。

三维成果包含计算书 DOCX 和同源 PDF，XLSX 全量结果归档，真实三维线框 DXF，逐层 XZ 平面、逐 Z 轴 XY 立面、逐 X 轴 ZY 立面 DXF/PDF，以及构件截面表、截面示意、输入快照、校核日志、清单和 ZIP。正投影每张标明切片坐标，仅绘制该面内实体构件，不连接跨面节点、不丢弃 Z 向构件；真实三维文件保留全部 XYZ。使用 R2018、真实 DIMENSION、A3 纸空间，图纸PDF从保存的DXF布局渲染。各轴平面单独分页，过密编号采用分页构件索引，防止缩小文字。

前端继续以预检判断能否生成，三维预检有效但始终标记方案草稿和 INCOMPLETE。不能仅根据收敛断言完整规范通过。原有单静力、扭转验算未覆盖、计算长度及连接深化等限制必须出现在报告与图纸中。缺少节点/引用、非法数值、零长构件、失败验算和结果不一致阻止输出；不补造公式/规范。缺少PDF转换器时保留DOCX/DXF/XLSX并返回partial。

网页CAD读取配套平面/立面图；真实三维线框通过原始DXF下载打开，不在网页压扁。复杂DXF只作预览及原文件下载，防止现有简易编辑器破坏块/尺寸定义。独立二维基准继续运行。
