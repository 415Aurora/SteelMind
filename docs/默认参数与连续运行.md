# 默认参数与连续运行

工作流1/2和网页模型输入允许缺失。默认教学参数：X/Z各1跨、1层、跨度6m、层高3m、固定柱脚、Q355、E=206000MPa、X向梁线荷载10kN/m、Z向5kN/m、楼层X/Z水平力5/2kN；恒/活荷载摘要5/2kN/m，风/地震摘要默认0。默认值仅供教学演示，不是地区规范荷载、勘察参数或安全设计结论。

后端 request_defaults.py 与前端 request-defaults.js 使用 dist/design-defaults.json 配置；测试逐项比较其归一化结果。修改配置需同步JS内嵌配置并运行 test-defaults.cjs。缺失/null/空白/空数组采用默认，0与false不会因“假值”被覆盖；非法整数、负几何及多项长度矛盾仍交原校验报错。单项数组按各层/各跨相同明确展开，记录采用值。候选列表缺失时使用默认；不改写用户明确提交的矛盾候选列表。

default_assumptions 记录 path/value/reason/profile；用户修改后移除不再适用的旧默认记录。默认输入传至工作流2 request/报告、三维输入快照、计算书和结果表；不生成默认分析结果、公式、条文或通过结论。原有方案草稿及INCOMPLETE保留。

使用：重启后端，Safari强制刷新；留空字段运行时会自动回填并显示可展开的默认假定说明。默认参数不能保证任意用户修改后的模型一定收敛或通过。空请求实测工作流1 preliminary、工作流2 converged、成果生成success；159项回归测试通过。
