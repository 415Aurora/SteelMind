# 三维成果链路交接说明

主项目：本目录 project/。已扩展三维工作流2 → 成果预检 → 工作流3 → 计算书、结果表、各层平面/各轴立面、三维线框及归档包。二维原契约保持兼容。

## 使用

1. 在原后端终端按 Control+C，然后执行同目录 start-backend.sh；前端按原 start-frontend.sh 启动。
2. Safari 按 Option+Command+R 强制刷新。
3. 重新运行工作流2。旧会话中的预检结果记录的是旧版“不支持三维”，必须更新。
4. 收敛并通过新版预检后，默认自动生成；关闭自动生成时点击“生成计算书/图纸”或运行工作流3。
5. 模型与成果中选择具体平面/立面 DXF 预览；三维线框通过下载按钮在 CAD 软件中查看。复杂图纸只读预览并原样下载，完整标注与文字查看配套 PDF，防止简易线段编辑器破坏尺寸块。

## 接口与分工

现有 POST /workflow/section-iteration/run[-stream] 和 /workflow/engineering-outputs/run[-stream] 入口不变，成果工具 generate_construction_drawing_package 按维度路由。输入仍为 {payload:{final_report:最终报告}}，响应保持 engineering_package 中 artifacts 的 name/url/bytes/sha256，新增 preview_mode：planar / download_only / document。

三维内部规范 SpatialResultBundle/1.0，保留 nodes/members/supports/reactions/sections/checks/iterations/parameters。Y竖向，X/Z平面；坐标m、位移mm、转角rad、力kN、力矩kN·m。绘图mm 1:1。截面使用逐构件最终权威快照，禁止同名属性互相覆盖。验算组需提供完整 analysis_demands、十二项 end_actions_local 和原始逐项 checks。局部轴单位向量逐构件归档，端力与沿程截面力不混用。

Python接口：tool_sources.spatial_export.normalize_spatial_report(report)、inspect_spatial_report(report)、generate_spatial_package(report,options,output_root)。真实字段样例在 tests/data/spatial_report.json；完整案例原始输入和规范化快照在相邻 SteelMind_三维完整案例_20261103/ 内。
